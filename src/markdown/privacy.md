# Privacy Policy · dotfn.dev

Última actualización: 2026-08-25

dotfn.dev es el sitio personal de Nicolás Jiménez. No tiene cuentas de usuario, no guarda datos de formularios en un servidor propio y no vende datos a terceros.

## Qué se recolecta

Vercel Web Analytics y Vercel Speed Insights, de forma agregada y anónima, sin cookies de seguimiento ni perfiles personales. No se usa Google Analytics ni rastreadores publicitarios de terceros.

## Almacenamiento local

Solo se guarda tu preferencia de tema (claro/oscuro) en el localStorage de tu navegador. Nunca sale de tu dispositivo.

## API de GitHub

`/api/github` lee datos públicos de contribuciones de la cuenta `dotfn` en GitHub para mostrar el calendario de commits en la home. No recolecta datos del visitante.

## Si me escribís

Los links de contacto abren tu cliente de email hacia dotfn.contact@gmail.com. Ese contenido se maneja como cualquier correo, fuera de este sitio.

## Hosting

El sitio está alojado en Vercel, que procesa las solicitudes HTTP (incluida la IP de la solicitud) según su propia política de privacidad.

## Contacto

Consultas sobre privacidad: dotfn.contact@gmail.com
